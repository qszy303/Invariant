## Scope and limits

- Every mutation edits the workbook (a formula, a typed cell or an export row).
- The Ledger is read from the export tabs, so an edit that keeps the export and the Runway consistent with each other is invisible by design (for example flipping a refund's sign inside Ramp itself). `sign_flip` is therefore injected in the Runway formula.
- A typed number that happens to equal the true value is not a bug and is not flagged; `stale_hardcode` types a value 2-8% off.
- `overlap_category` fires `no_double_count`; `traceability` does not, because the spec is read from the same (buggy) formulas, so the sheet and its own spec agree.
- The suite is synthetic (one company shape, five seeds). Detection rates say what the checker does on this family, not on arbitrary real models.
